# 💼 MN Portfolio

My personal developer portfolio website, showcasing my background, technical skills, and projects as a Java Full Stack Developer.

🔗 **Live Site:** [mn-portfolio-alpha.vercel.app](https://mn-portfolio-alpha.vercel.app/)

## 📌 Sections

- 🏠 **Home** — Introduction and quick overview
- 🎓 **Education** — MCA (NIST University) and B.Sc. Physics (Berhampur University)
- 🛠️ **Skills** — Java, Spring Boot, HTML, CSS, JavaScript, React, SQL
- 💻 **Projects** — Showcases of completed full-stack and frontend projects
- 📩 **Contact** — Email, LinkedIn, and GitHub links

## 🛠️ Tech Stack

- React
- HTML5
- CSS3
- JavaScript
- Deployed on Vercel

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/MalayaNayak2002/mn-portfolio.git
   ```
2. Navigate into the project folder:
   ```bash
   cd mn-portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
